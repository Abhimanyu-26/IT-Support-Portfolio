# No Internet Because the Network Adapter Is Disabled

*Tested in a Windows 11 virtual machine.*

## Symptom

The customer says, "I can't open any website."

## Cause

The network adapter (the part of the computer that connects to the internet) was switched off.

## Steps to fix

1. Right-click the Start button and click **Device Manager**.
2. Click the small arrow next to **Network adapters** to open the list.
3. Find the adapter that has a down-arrow icon on it. That icon means it is disabled.
4. Right-click it and click **Enable device**.
5. Wait about 10 seconds for the connection to come back.
6. Open Chrome or Edge and try any website.

## Expected result

The website opens, so the problem is fixed.

## If it still doesn't work

Restart the computer and try again. If it still fails, escalate the ticket with the steps you tried.
